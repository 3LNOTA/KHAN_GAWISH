# ☕ نوتة المعلم - نظام إدارة شكك وحسابات القهوة البلدي

نظام متكامل، سريع، وسهل جداً لإدارة ديون وشكك الزبائن في القهوة البلدي في مصر، مصمم خصيصاً ليناسب طبيعة القهوة الشعبية ويقضي على مشاكل النسيان وضياع الدفتر وخلافات الحسابات.

---

## 🌟 أبرز مميزات النظام

1. **تسجيل الطلبات في ثوانٍ (الكاشير):**
   - شبكة أزرار سريعة لمشاريب القهوة والشيشة (شاي كشري، قهوة تركي، سحلب، حجر قص، سلوم...).
   - إمكانية الدفع كاش فوري أو التسجيل على النوتة بضغطة زر.

2. **📲 إشعار فوري للزبون عبر WhatsApp:**
   - بمجرد تسجيل أي طلب على النوتة، يتيح لك النظام إرسال رسالة واتساب فورية للزبون برصيده الجديد وتفاصيل طلبه بنص مصري ذوق واحترافي لمنع أي خلاف مستقبلي.

3. **🛡️ الحد الائتماني الذكي (Credit Limit):**
   - تحديد سقف لكل زبون، وتنبيه فوري ملون إذا اقترب أو تجاوز الحد المسموح به.

4. **💰 السداد ودعم الدفع الإلكتروني:**
   - سداد جزئي أو كلي للحساب (كاش، فودافون كاش، InstaPay).
   - إرسال تذكير لطيف بالدفع يحتوي على أرقام السداد الإلكتروني.

5. **📊 لوحة تحكم المعلم (Dashboard):**
   - إجمالي الفلوس اللي في السوق بره (حجم الديون المعلقة).
   - إجمالي التحصيلات ونسبة السداد.
   - كشف الحسابات الأعلى مديونية لترتيب أولوية التحصيل.
   - حماية لوحة المعلم برقم سري (PIN) لمنع تلاعب العمال.

6. **📁 حفظ محلي ونسخ احتياطي:**
   - كل البيانات تحفظ تلقائياً على جهازك في الـ LocalStorage.
   - تصدير واسترجاع نسخة احتياطية كاملة (Backup JSON) بضغطة واحدة.

---

## 🚀 طريقة التشغيل

1. **التشغيل الفوري المباشر:**
   - اضغط مرتين على ملف `start.bat` أو افتح ملف `index.html` مباشرة في أي متصفح (Chrome, Edge, Safari).
2. **أو التشغيل عبر سيرفر محلي (Python):**
   ```bash
   python server.py
   ```
   وسيفتح المتصفح تلقائياً على الرابط: `http://localhost:5050`

---
*الرقم السري الافتراضي لشاشة المعلم: `1234` (يمكنك تغييره من الإعدادات).*
